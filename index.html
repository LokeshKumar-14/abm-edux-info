Too many apps for one course

WhatsApp for updates, one app for video, another for PDFs, tests tracked by hand, a separate app for live class, payments handled somewhere else entirely.

Students end up with no single place for their learning journey, and teachers juggle a different tool for every part of running a course. ABM EduX replaces that patchwork with one integrated platform — courses, video, live classes, materials, tests, assignments, payments and community, all in the same app.

What it brings together

Recording upload & review

Live classes, recorded your way

Real-time teaching with Agora RTC, plus a recording workflow that doesn't depend on the cloud.

Local recording

Recording happens on the phone — merge the clips when you're done

Live sessions can be recorded straight to local storage, organized by course, so a session doesn't need to be uploaded live to be captured.

If a class gets recorded in parts, multiple local segments from the same session can be merged into a single clean video file — then played back, deleted, or uploaded to Firebase Storage for the course library.

Recordings/ {courseId}/ recording1.mp4 recording2.mp4 recording3.mp4 ↓ merge session-final.mp4
